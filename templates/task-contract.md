# 작업 계약 양식

각 항목을 실제 작업에 맞춰 작성한다. 불필요한 항목은 생략한다.

- 목표와 요구사항:
- 조사 질문·비교 기준·필요한 근거와 출처:
- 작업 단위·의존 관계:
- 담당 소스·테스트 경로 / 다른 워커와 공유하는 범위:
- 보호 파일·작업 전 기존 변경:
- 필수 검증 명령·추가 테스트·완료 조건:
- 사용 가능한 조사 도구와 편집·실행 권한:

하나의 지속 세션에서 상세 조사·구현·테스트·자체 검토·범위 내 수정을 수행한다. 의존성 폴더의 재귀 목록과 무관한 대량 출력을 피한다. 다른 작업자의 변경을 보존하며 추가 워커·모델 변경을 하지 않는다.

조사 전용이면 편집을 금지한다. 사실·추론·미확인 사항을 구분하고, 조사 결과에는 확인한 출처와 판단 근거를 남긴다. 도구가 없거나 접근이 막히면 조사 완료로 추정하지 않는다.

완료 시 바뀐 파일, 실제 명령·종료 코드, 핵심 검증 근거, 자체 검토 결과, 미해결 문제를 간결하게 전달한다. 해결할 수 없는 차단은 실패한 작업과 근거를 보고한다. 조사 결과가 다른 작업의 선행 조건이면 그 의존 관계를 명시한다.
